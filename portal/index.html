模块一

活动全流程（报名 · 签到）

活动前与活动中的运营主战场：多来源报名统一接入、重复识别与合并、现场签到回传、账号权限与服务提示。

  • 群接龙 / 小程序 / 代报名单解析导入
  • 重复报名分组、合并与留痕
  • 现场签到、纸质表誊录回传
  • 历史信息库自动补全、社工 / 志愿者 / 家长端

模块二

活动档案管理台（活动后归档）

活动结束后的收口：8 类资料齐备度检查、G3 归档卡点、台账与照片索引、三类导出包。

  • 总览看板 / 活动档案 / 归档工作站
  • 待办中心、人员身份库
  • 导入模块一导出的报名与签到名单
  • 内部留档包 / 年检包 / 基金会备案包（脱敏）

模块三

童颜守护（儿童照片脱敏）

对外发布前的照片处理：人脸检测 + 年龄判断，马赛克 / 模糊 / 卡通笑脸三种打码方式。

  • 自动识别儿童人脸，可手动补框复核
  • 原图不上传，仅保存打码后的图片
  • 处理后的图片存入服务端，供归档台引用
进入模块 →
使用与共享提示
1. 模块一（报名签到）需要登录。演示账号与口令由服务端配置提供，见 config.example.env 与登录页「演示账号一键登录」；志愿者与家长用手机号验证码登录。生产环境请关闭演示登录并覆盖全部默认口令。
2. 三个模块的数据都保存在服务端，拿到链接的人都能读写。请勿在公开渠道传播链接，也不要录入真实儿童敏感信息做演示。
3. 模块二、模块三目前不设登录，如需限制访问请在模块一「账号权限」之外另行加一层网关。
